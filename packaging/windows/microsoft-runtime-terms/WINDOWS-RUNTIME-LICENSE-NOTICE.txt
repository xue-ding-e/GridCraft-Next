WINDOWS RUNTIME TERMS

Scope
The GridCraft-Next Windows GUI and command-line executables contain embedded
Microsoft release static C runtime code: libcmt and libvcruntime from MSVC
14.44.35207, and the Universal C Runtime (libucrt) from Windows SDK
10.0.26100.0. No standalone runtime .lib files or development tools are included.
